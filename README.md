## โครงสร้างโมเดล

Star schema — fact 1 ตาราง, มิติ 5 ตาราง, ตารางตัวชี้วัด 1 ตาราง

| ตาราง | บทบาท | หมายเหตุ |
|---|---|---|
| `สินเชื่อ` | fact | ยอดคงค้าง วงเงิน ภาระผูกพัน พร้อมคุณลักษณะระดับวงเงิน (สถานะ ชั้นความเสี่ยง ระดับการใช้วงเงิน อายุความสัมพันธ์ ช่วงยอดคงค้าง ประเภทเครดิต โครงการ ฝ่าย ส่วน) |
| `วันที่` | มิติ | ปฏิทินรายวันต่อเนื่อง `dataCategory: Time` แกนหลักคือ `ปี` (พ.ศ.) |
| `ลูกค้า` | มิติ | 1 แถวต่อลูกค้า ชื่อจากปีล่าสุด พร้อม segmentation ระดับลูกค้า |
| `อุตสาหกรรม` | มิติ | ประเภทธุรกิจ 182 รายการ จัดกลุ่มเป็น 10 กลุ่มอุตสาหกรรม |
| `ประเภทสินเชื่อ` | มิติ | 5 ประเภท จัดกลุ่มเป็นสินเชื่อหมุนเวียนกับระยะยาว |
| `ขนาดลูกค้า` | มิติ | S / M / L เก็บบน fact เพราะขนาดของลูกค้าเปลี่ยนได้ระหว่างปี |
| `ตัวชี้วัด` | measures | 34 measure ไม่มีข้อมูลของตัวเอง (รวม measure `อันดับ...` ที่ใช้ทำ Top N) |

ตัวเลขเงินทุก measure อยู่ในหน่วย **ล้านบาท**

## Segmentation

ตรงกับที่วิเคราะห์ไว้ใน [out.ipynb](out.ipynb) แต่ล้างข้อมูลเพิ่ม

- **อายุความสัมพันธ์** — ปีของภาพข้อมูล ลบ ปีที่ตั้งการ์ด แบ่งเป็น <3 / 3-4 / 5-9 / 10+ ปี
  (ทิ้งปีที่ตั้งการ์ดที่เป็นค่าผิดอย่าง 0 หรือ 9999 จำนวน 27 แถว)
- **กลุ่มความต่อเนื่อง** — จำนวนปีที่ลูกค้าปรากฏในพอร์ต 1-2 / 3-4 / 5-7 / 8-10 ปี
- **ระดับการใช้วงเงิน** — ยอดคงค้าง หารด้วย วงเงิน แบ่งเป็น ไม่เบิกใช้ / <20% / 20-50% / 50-80% / 80%+
- **ความหลากหลายผลิตภัณฑ์** — จำนวน `product_code` ที่ต่างกันต่อลูกค้า 1 / 2-3 / 4+
- **ชั้นความเสี่ยง** — ล้าง `Final Rating` ให้เหลือ A, B1-B4, C1-C3, D, TDR ที่เหลือเป็น "ไม่จัดชั้น"
  (ต้นทางมีทั้งค่าที่มีสระไทยนำหน้าและค่าที่เป็นคะแนนตัวเลข)

## หน้ารายงาน

1. **ภาพรวมพอร์ต** — KPI, วงเงินเทียบยอดคงค้างรายปี, YoY, สัดส่วนตามขนาด/อุตสาหกรรม/ประเภทสินเชื่อ
2. **อุตสาหกรรม & ขนาด** — % ยอดคงค้างรายอุตสาหกรรม, เทียบกับ % วงเงิน, treemap, Utilization แบบตาราง
3. **ยอดคงค้างตามเวลา** — stacked รายปีตามขนาด, Utilization รายปี, ดัชนีการเติบโต, ลูกค้าใหม่เทียบเดิม
4. **ประเภทสินเชื่อ** — Top 10 ประเภทเครดิต, ยอดตามประเภทสินเชื่อ, Top มาตรการพิเศษ, สัดส่วนหมุนเวียน/ระยะยาว
5. **Utilization รายลูกค้า** — KPI การใช้วงเงิน, กระจายตามระดับ, scatter วงเงินเทียบยอดคงค้าง, ตาราง Top 20
6. **Insight & ความเสี่ยง** — NPL / Stage 2, การกระจุกตัว (Top 10 share, HHI), ชั้นความเสี่ยง, cross-tab

slicer ทั้ง 5 ตัว (ปี ขนาด อุตสาหกรรม สถานะ ประเภทสินเชื่อ) sync ข้ามทุกหน้า
